# v0.1.4-r2b 打开界面修复

用户在 v0.1.3 中仍能看到原生设置折叠栏，但点击「打开实验台」无效果。尚未取得其设备的控制台日志，不能声称已经确认唯一根因。

旧测试只在 jsdom 检查 class 和 hidden 状态，没有加载真实 CSS，也没有检查浏览器可见性。这个覆盖缺口已确认。

本版调整：
- bootstrap.js 加载原决策模块；panel-host.js 单独处理打开与关闭，不变更判定、提示词或注入语义。
- 使用 SillyTavern.getContext().Popup 原生弹窗，替代旧自制 fixed 遮罩；不再以提升 z-index 作为主要修复。
- 点击入口使用捕获阶段委托，兼容设置节点被其他布局扩展重建的情况。不代表已确认用户安装的任何扩展是根因。
- 新增「在当前栏打开（兼容模式）」，不依赖弹窗。保留同一组输入与结果节点，不克隆丢失事件。
- 设置栏显示「界面 0.1.4-r2b」和具体打开/失败状态。未出现该行表示新入口模块尚未加载。
- 原生弹窗不存在时自动退回栏内显示。未配置辅助模型也不应阻止打开界面。
- 打开、关闭与切页不调用模型，不更改世界书、角色卡或聊天状态。

## 验证范围
新增 Playwright Chromium 手机尺寸触屏和桌面测试，使用仓库真实 ES 模块和 CSS；宿主接口用兼容 mock，不能代替用户酒馆实测。检查可见性、点击、切页、关闭重开、节点替换后仍可打开、栏内备用、模型配置缺失和零模型请求。

## 更新后使用
在酒馆更新至 v0.1.4-r2b 并刷新网页。展开 NPC · 人物决策，确认版本行出现。可先点击「在当前栏打开（兼容模式）」直接继续使用；正常入口会使用酒馆原生弹窗。若仍失败，请截图版本行与其错误文字，不需调用模型或清空存档。
