# v0.2.0 独立渠道配置阶段

## 实际完成范围
渠道添加/编辑/删除、固定官方地址、隔离保存密钥、模型列表读取、四个阶段模型选择、显式单次短测试。当前聊天自动取材、自动人物映射、辅助判断的正常入口尚未接通，不宣称能自动改善真实游戏人物。旧样本仅保留在主动展开的回归区。

## 安装
按照根 README 的步骤在酒馆电脑安装配套服务：停止酒馆、备份 config.yaml、将本仓库克隆到 plugins/npc-independent-api，手工检查其他服务器插件并启用 enableServerPlugins，然后重启酒馆。软件不会自动修改安全配置。服务器插件有主机权限，只安装可信代码。

网页与服务器是两个安装副本。手机更新网页扩展不能替代服务器重启/更新；后续服务器副本可随酒馆的服务器插件自动更新配置更新，或手工 git pull --ff-only。无需反复下载上传 ZIP。

## 已实现协议范围
OpenAI、Google AI Studio、Claude、DeepSeek、OpenRouter、硅基流动和自定义 OpenAI-compatible：模型列表及非流式文本生成适配。硅基模型列表使用官方 GET /v1/models?sub_type=chat；来源 https://api-docs.siliconflow.cn/docs/api/models-get 。

火山方舟（北京按量API）可明确手填模型 ID，列表发现仍未实现。Vertex 项目认证未完成，界面禁用。不要把开发预设元数据当作已完成认证适配。模型出现在列表也不能证明有调用权限、余额或所有参数兼容。

## 独立请求语义
配置保存/阶段选择不调用模型；模型列表只调用列表接口。测试必须确认可能收费，固定内容 Reply with OK only.，输出预算64，输入不带聊天/卡/世界书；不自动重试或换主接口。厂商可能将思考计入不同的预算/账单；没有可见输出不代表没花钱。

正常独立生成端点已具备指定阶段路由，但尚未从前端接到当前聊天判断。一次明确调用只选一个渠道和一个模型，不能把四个阶段自动串成四次请求。

## 密钥安全边界
服务端按酒馆当前登录用户目录隔离，不读写正文 secrets.json。密钥加密后保存在 npc-independent-api/channels.json，master 材料为同目录 vault.key；必须共同保护备份，服务器管理员仍然可以解密。浏览器不回读已存 Key，眼睛按钮只显示正在填写的新内容；日志与错误不返回提供商原始响应体。

更换地址/提供商须重新输入密钥；实际服务器验证官方地址，不信任仅前端只读。HTTPS443公网IPv4出站、DNS地址固定、禁私网/保留地址、拒绝重定向、输入与响应上限、超时、每用户单任务并发限制。没有开放CORS，也不自动修改酒馆认证/CSRF配置。

手机到酒馆公网HTTP不可填写密钥，局域网HTTP需确认可信网络，优先HTTPS。此实现不是支持任意局域网模型的通用代理。

## 检查
29项单元/安全/协议测试加真实浏览器手机和桌面操作测试；所有提供商响应与密钥均为测试假数据，不会产生付费模型请求。测试宿主与生产酒馆不同，真实接口访问仍需用户小额验证。

状态条与操作结果同步：连通测试完成后不能继续显示“尚未调用模型”。原 Connection Profiles 刷新仅保留在主动展开的旧回归区，不覆盖正常渠道状态。
