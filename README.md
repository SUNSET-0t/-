# NPC 人物决策 · 简单设置版 v0.3.1-r2b

**默认只配置一个辅助接口、一个模型。**不需要选择四个阶段，不需要配套服务、电脑命令或修改 config.yaml。

安装地址仍为 `https://github.com/SUNSET-0t/-`。更新网页扩展后刷新页面，顶部显示 `0.3.1-r2b`。原来的渠道、密钥引用、模型列表和分阶段设置均保留，不需要重新填写 Key。

## 最简单的使用方式

设置 → 选已保存的辅助接口 → 获取模型列表 → 选一个模型 → **保存并统一使用**。

第一次没有接口时：配置辅助 API → 选服务商 → 填 Key → 保存接口，再返回选择模型。官方地址自动填写并折叠，中转地址使用自定义。接口名称与请求参数都可保持默认。

“保存并统一使用”将各任务使用的模型统一成当前选择，不会运行四次模型。只有明确点击“测试连接（可能收费）”并确认，才发送一次固定短请求。模型列表和配置保存不生成正文。

## 简单模式与高级设置

默认页面不展开渠道列表和四阶段表格。管理已保存接口放在折叠区，分阶段模型放在“高级设置（可以不动）”。

已有的不同阶段设置不会被悄悄覆盖；新版启动只读取，选择统一模型时需确认。四阶段是后续内部任务分工：整理人物资料、普通重要互动、复杂冲突与多轮积累，不要求四种不同模型。

模型来自所选接口实际响应，支持搜索和明确的手动 ID。不存在“越贵一定越合适”的自动推荐，也不把四个槽当固定四次请求。

## 密钥框与 Chrome 提示

旧版把 API Key 放在带 new-password 标记的密码表单里，容易被浏览器当作账号密码。新版去掉登录表单结构，支持的浏览器使用普通 token 输入框与视觉遮罩，仍可切换显示/隐藏，保存及关闭后清空输入。

这不改变原生 Key 存储，不把 Key 写入普通设置。视觉遮罩只保护读屏，不是加密。没有修改用户浏览器的密码管理开关，也不读取或删除 Google 已保存密码。

**网页不能保证所有 Chrome/Android 密码管理版本都不提示。**自动测试验证表单语义、遮罩和清空行为，无法验证用户登录的 Google 密码管理器原生弹层。不支持 CSS 遮罩时退回密码框并提示其限制。

## 实际功能边界

目前完成渠道配置、模型列表、阶段选择和显式短生成测试。**当前聊天自动取材、人物建档、自动生成前判断尚未接入**，这次界面简化不代表人物逻辑已经完成。正常界面不导入固定故事/人物/日期。

底层仍复用酒馆原生同源接口，不依赖旧0.2配套服务，不切换正文 model/source/url；没有自动昂贵正文回退、自动重Roll或日志上传。

## 提供商与密钥行为

OpenAI、Google AI Studio、OpenRouter、硅基使用酒馆对应原生源；DeepSeek/自定义中转用明确 custom 地址与密钥ID。Claude和火山方舟暂需手填模型ID；Vertex项目认证未接入。具体能力受酒馆版本和服务商权限影响。

Key 保存到酒馆自己的密钥库，插件设置只保存引用。新增Key后恢复原默认项并校验；复用已有ID不更改默认项。这是多步恢复，不是服务器原子事务；保存时不要在其它窗口同时更换Key或发送同类默认请求。异常恢复尚未确认时阻止当前页面继续生成。未曾配置的类型保留空默认项，不让辅助Key成为正文有效默认。

不调用密钥明文回读接口，不要求 allowKeysExposure。删除接口不自动删除酒馆Key，避免破坏其他引用。原生存储边界与酒馆相同，不能对服务器管理员提供隔离。完整说明见 docs/NATIVE_TRANSPORT_DECISION.md。

## 测试

原生凭据/请求测试基于固定上游 secrets 源码、假密钥和模拟服务商；简单设置测试覆盖已有配置保留、统一时确认、一个模型完成配置、没有隐式生成。真实Chromium测试覆盖320/393像素触屏及桌面、宿主按钮样式、原生弹窗与栏内模式、视觉遮罩和关闭清空。

测试不使用真实提供商Key，不产生真实模型费用。用户酒馆环境、Chrome密码提示及具体服务商仍需实际确认。细节见 docs/SIMPLE_UI_031.md。
