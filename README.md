# NPC 人物自主模拟 · 自动运行版 v0.4.1-r2b

配置一个辅助 API 和模型后，照常聊天即可。无需手工判定/注入、额外服务、电脑命令或修改config.yaml。已有接口、Key引用和阶段模型继续保留。安装地址不变：`https://github.com/SUNSET-0t/-`。

## 本次修复：DeepSeek辅助输出被截断

0.4.0默认2048输出额度没有充分处理思考+JSON共用预算，并在长度错误时丢失了usage详情。0.4.1在自动人物判断中，对已识别DeepSeek V4.1 Flash且沿用2048/default组合的请求，使用8192总生成上限；OpenRouter/DeepSeek已核对官方接口明确请求low思考，不关闭思考、不自动续写、不重试。其它显式手动额度/思考设置保留。

自动适配不修改已存渠道或正文设置；更新并刷新即可使用原Key。8192是请求上限，不是必花用量，但会提高允许的最坏辅助费用。low不是硬性思考token上限，仍不能保证所有场景不会截断。未知中转地址不猜专有参数。故意要保留旧2048/default的用户可在进阶选择“严格使用接口中保存的参数”。

运行页新增有效请求上限/实际输出用量/思考用量/可见结果长度；接口未提供时明确未知，不显示或存储原始思考。长度截断不代表余额不足，仍在发送正文前暂停。完整说明见docs/OUTPUT_BUDGET_041.md。

## 操作

第一次：API设置 → 配置辅助接口 → 填Key并保存 → 获取模型列表 → 选一个模型 → 保存并统一使用。已有配置直接更新、刷新后正常发送消息。

默认一次辅助请求同时整理相关人物与判断立场，临时注入同一轮正文，原主模型再生成一次。没有生成后审核、没有自动正文重Roll。四阶段是可选路由，不是四个串行调用；明确快进使用已配置review、重大冲突优先complex，其余regular，缺少对应项使用已指定regular，不回退正文模型。

普通页面显示等待配置、读取、判断、已注入、已参与、跳过或失败。“已参与”须在最终正文请求中确认摘要标记。记录与进阶只用于观察依据/实际文本，正常不必操作。

多数剧情互动会调用一次辅助生成。明确背包/状态查看默认跳过；继续和日常含蓄互动仍判断。相同材料与参数的手动重生成可以在本页面复用已通过校验的判断。辅助失败显式暂停正文，不自动换模型；可主动选择“仅下一轮跳过辅助判断”。取消已发出的辅助请求不保证服务商不计费。

## 范围与限制

当前默认最近8条历史消息、角色卡、相关世界书限量材料；约18000字符预算不是token。最多12本关联书、10条条目候选、4位相关NPC。不是完整持久记忆，超过窗口的重要经历可能缺失。复杂世界书触发条件未完全模拟，保守跳过并提示；不第二次运行主模型世界书激活扫描。

规划、玩家意图、私人内心、离场事件、摘要与数值声明分开处理，结构校验不等于模型语义完全正确。目标是人物自己的动机，不预设拒绝、吃醋、降好感或玩家成功。保留咩咩预设、合理扩写玩家行动和平行线，不修改角色卡、世界书、原聊天或好感数值。

## API与密钥

复用酒馆同源原生后端；普通插件设置只保存Key编号，明文送原生密钥库；不调用完整Key回读、开发者中转或额外服务。新增Key后恢复默认项是多步非原子操作，保存期间不要在另一窗口同时更换Key。既有原生渠道适配限制仍适用：Claude/火山可手填模型，Vertex认证尚未实现。

## 验证

固定上游SillyTavern密钥代码、生成前hook与prompt收集器用于自动测试；其余宿主和提供商响应模拟，所有Key为假数据。覆盖手机/桌面普通发送、同轮注入、默认Key不变、简单设置回归、错误不发正文、取消/分支、输出预算与usage诊断。测试不调用付费模型，不等于全部真实提供商/插件并发/人物语义已验证。
