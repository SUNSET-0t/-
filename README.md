# NPC 人物决策 · 独立渠道实验版 v0.2.0-r2b

SillyTavern NPC 自主模拟项目，从零开发，不使用旧仓库的 Claude 判官代码。

**这是独立 API 配置阶段，不是完整 NPC 引擎。**当前可以管理独立渠道、固定官方地址、隔离保存密钥、读取实际模型列表、按阶段保存模型选择及手动短生成测试。当前聊天自动取材与真实人物决策接线尚未完成；阶段配置不会自行发起人物判断。

## 使用前必读

这版包括浏览器扩展和一个服务端配套模块。**仅更新网页扩展可能显示“独立服务未安装”，这是明确的安装状态，不是弹窗再次坏了。**密钥输入在服务准备好前禁用；不自动回退正文 API。

## 网页扩展

酒馆扩展管理的仓库地址保持：

```text
https://github.com/SUNSET-0t/-
```

更新至 `0.2.0-r2b` 后刷新网页。魔杖 → NPC · 人物决策，或扩展设置的原生折叠栏，均保留原生弹窗与栏内备用入口。

## 一次性安装独立服务（运行酒馆的 Windows 电脑）

1. 停止酒馆，备份根目录的 `config.yaml`。在酒馆根目录（能看到 config.yaml、Start.bat 等文件的位置）打开终端。
2. 若 `plugins/npc-independent-api` 尚不存在，运行：

```text
git clone https://github.com/SUNSET-0t/- plugins/npc-independent-api
```

3. 检查 `plugins` 文件夹，只保留你信任的服务器插件。手工将 config.yaml 的 `enableServerPlugins` 设为 `true`。本插件不会自动改写该开关。启用后该目录中的其他服务器插件也会运行，服务器插件不受浏览器沙箱保护。
4. 重启酒馆，手机刷新页面。在“设置”看到“独立服务 0.2.0 已连接”后再填写渠道。

已存在同名目录时不要重复 clone 或删除：进入该目录检查内容；确认为本仓库后可运行 `git -C plugins/npc-independent-api pull --ff-only` 更新，再重启酒馆。

后续无需手动上传 ZIP：网页扩展按原按钮更新，服务端副本按酒馆服务器插件自动更新设置在重启时检查更新；关闭该设置时手动 git pull。只刷新手机不会重启 Node 服务。

## 渠道编辑

添加渠道 → 选择提供商 → 填独立密钥 → 保存 → 获取模型列表 → 选择默认模型 → 保存。官方地址固定只读，第三方中转选“自定义”。同一提供商可创建多个命名渠道。

阶段选择：资料整理、常规人物判断、复杂人物判断、累积变化检查；可全部沿用同一配置。**四个槽位不是每轮四次调用。**本版本只保存分工，自动调度仍未启用。

支持列表与生成适配：OpenAI（GPT）、Google AI Studio（Gemini）、Anthropic（Claude）、DeepSeek、OpenRouter、硅基流动、自定义 OpenAI-compatible。火山方舟暂时手填已开通模型 ID，列表发现未接入。Google Vertex AI 项目认证暂未实现，界面禁用。原生 Gemini/Claude 与 OpenAI-compatible 分别构造请求，不假装一套参数兼容所有模型。

## 收费与行为

- 打开界面、保存配置和阶段选择：不调用生成模型。
- 获取模型：访问所选服务商模型列表，不调用正文或生成端点；返回空/错误时如实显示，不填充虚构型号。
- 测试生成：必须确认可能收费；只发一次固定短请求，不带游戏正文。输出预算64，不重试，不自动换模型。思考费用/最低计费规则以服务商为准。
- 没有自动重 Roll，不修改世界书、角色卡、咩咩预设或正文接口。
- 固定测试人物已从正常首页移除；旧实验仅在设置内主动展开的回归区，且明确不代表当前聊天。

## 安全与限制

密钥按酒馆用户独立保存在 `npc-independent-api/`，不写正文 secrets.json 或普通浏览器设置。AES-GCM 加密与同机 vault.key 防止误导出明文，但不能抵御有文件权限的服务器管理员。需要保护整套数据备份。

公网 HTTP 页面禁止填写密钥；局域网 HTTP 需明确确认可信网络，优先 HTTPS。独立服务仅转发 HTTPS443 公网IPv4，不支持内网/本机 API；拒绝重定向、私网DNS和越界输入。使用酒馆登录、CSRF及额外请求头检查，不会自动降低酒馆安全设置。

当前仅非流式；模型 ID 列出不保证调用权限。价格没有核实就显示未知。失败不自动重试。当前真实聊天提取、长期状态、多轮自动调用、NPC判断效果和用户酒馆兼容性仍待后续验证。
