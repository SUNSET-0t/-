# NPC 自主模拟系统 · R2-B 决策实验台

面向 **SillyTavern** 的全新独立实验扩展。旧版 `SUNSET-0t/NPC-` 的 Claude 判官已弃用，本项目从零实现。

**当前状态：可安装的 R2-B 手动测试工具，尚不是正式 v1.0 NPC 引擎，也尚未在用户的酒馆环境中实测。**

## 安装

在 SillyTavern 的 **扩展 → 安装扩展** 输入：

```text
https://github.com/SUNSET-0t/-
```

安装并刷新酒馆页面后，在扩展设置中查找 **NPC R2-B · 决策实验台**。

## 首次测试流程

1. 在酒馆 Connection Profiles 中准备一个独立的低成本模型配置（Flash-Lite 级模型可作候选）。不要选运行正文的昂贵 Gemini 4a 连接。
2. 在插件扩展设置中选择该连接配置。插件只在点击 **运行独立判官** 时才调用它，不会擅自调用主模型。
3. 选择 **B · 短指令人物立场（stance）**，点击 **载入样本**，然后 **运行独立判官**。
4. 查看并复制原始 JSON，人工检查认知范围、人物自己的议程和条件判断。结构校验通过不代表人格模拟已经正确。
5. 如要测试正文演绎，请先切到**1月16日拒绝邀约后的剧情测试分支**，不继承之后候选剧情，打开插件的 **正文注入** 部分，点击 **注入下一轮正文**。
6. 在酒馆聊天框正常发送：`（接下来几天照常与萧炎、萧薰儿相处，在日常小事上自然地多关心薰儿一些，含蓄表达好感，暂不表白，也不刻意排除萧炎。）`
7. 正文仍由你选择的主模型按原角色卡、世界书和咩咩预设正常生成**一次**。注入只使用一次，不自动重 Roll。

**A · 具体事件下一行动（decision）** 是已发生送栗子事件的单独判定样本，**不能直接注入1月16日尚未发生相关事件的节点**。这两种测试使用一套通用提示词，测试人物 A/B/C 是样例资料，不是硬编码的判断规则。

## 本版本不做什么

- 不自动扫描整本世界书、完整长剧情或自动构建 NPC 档案；
- 不自动每轮调用第二模型；不自动生成后审核或重新生成昂贵正文；
- 不改动原世界书、咩咩预设、人物关系数值、聊天存档或角色卡；
- 不提供长期记忆、自动状态恢复、跨分支快照或精准 API 费用统计；
- 不保证低成本模型一定能维持复杂 NPC 的长期人格一致性。

## 技术构成

- `manifest.json`：SillyTavern 插件声明与 generate_interceptor
- `index.js`：扩展 UI、Connection Profiles 辅助模型调用、JSON 校验及一次性生成前注入
- `prompts.js`：通用人物决策规则与注入模板
- `fixtures.js`：高关系短指令、明确事件两份测试材料
- `style.css`：手机端适配

## 维护与版本

此仓库已通过 ChatGPT GitHub 连接成功写入，今后的更新可直接提交代码，不需要用户每次下载并重新上传 ZIP。酒馆是否自动检查到更新取决于 SillyTavern 设置；未提示更新时可以在扩展管理中手动检查更新。

正式 v1.0 将在 R2-B 人物决策效果经过测试以后，再逐步开发自动识别、智能调度、状态存储、重 Roll 与剧情分支一致性等能力。
