# NPC 人物决策 · 原生调用版 v0.3.0-r2b

**只安装/更新酒馆网页扩展即可。不需要配套服务，不改 config.yaml，不执行电脑命令。**

安装地址保持 `https://github.com/SUNSET-0t/-`。更新后刷新网页，面板标题应显示 `0.3.0-r2b`。入口使用版本化文件，旧渠道服务不再影响页面，也不要求清除所有网站数据。

## 已实现

插件内添加渠道，常用官方地址自动填写；密钥通过酒馆原生密钥管理保存，之后按密钥 ID 调用。可直接选择酒馆已有密钥。模型列表从对应渠道通过酒馆原生接口获取，不放固定型号。每个阶段分别选渠道/模型，或者全部沿用常规判断。阶段是分工，不是每次依次调用四次。

实际生成使用 `/api/backends/chat-completions/generate`，模型列表使用 `/api/backends/chat-completions/status`。不是调用当前正文预设，不更改正文 model/source/url，也不经过开发者中转服务器。没有 Key 回读接口、普通设置明文保存或自动昂贵模型回退。

当前仍是渠道连接阶段。**自动读取当前聊天/世界书、人物建档、生成前自动人物判断尚未接入**；正常界面不再导入旧固定人物 fixture。没有把未完成的功能做成可点击的成功假象。

## 手机操作

魔杖 → NPC · 人物决策 → 设置 → 添加渠道 → 选择提供商 → 填 Key → 保存渠道 → 获取模型列表 → 选择模型 → 保存。

第一次可以只保存并获取模型列表。“测试生成”会明确询问是否允许可能收费的一次短请求；不发送游戏聊天，插件不自动重试、也不生成正文。

无需先配置 Connection Profiles。模型选择器支持搜索和明确的手动 ID 模式。接口未返回列表时显示错误，不填充内置名单。

## 提供商差异

OpenAI、Google AI Studio、OpenRouter、硅基流动使用酒馆对应原生源；DeepSeek、自定义中转通过酒馆 custom 源使用明确地址与 Key 引用。火山方舟按量接口需要手填已开通的模型/接入点 ID。Claude 可通过酒馆原生生成，但当前核对的 status 接口没有 Claude 模型发现路由，需要手填。Vertex 项目认证暂未支持，明确禁用，不借用正文配置。

支持范围受你的酒馆版本及服务商权限影响。旧版布尔形式密钥接口不支持引用时会明确提示升级酒馆，不改用正文默认 Key。

## 密钥保存的真实行为与边界

Key 存在酒馆自己的 secrets.json；插件普通设置只保存渠道地址、模型、参数和 Key 编号。不会读取 /secrets/find、/secrets/view，也不要求开启 allowKeysExposure。原生库的保护程度与酒馆本身一致，不宣称是对管理员隔离或加密保险库。

酒馆原生新增 Key 会临时激活该 Key，当前原生 API 没有“非活动追加”事务。因此本插件在新增后恢复之前的默认 Key 并校验；从未配置该类型时，留下一个空默认项，使辅助 Key 不成为正文有效默认。选已有 Key 完全不写默认项。**这是有恢复检查的多步保存，不是服务器原子事务。**保存期间请勿在其它窗口同时修改密钥或启动同类型请求。当前页面的生成会等待保存结束，保存失败且恢复未确认时会阻止继续生成并显示提示。

恢复日志只存 ID/标签、不存 Key。恢复只处理仍由本次新增项占用的默认状态，不覆盖其它窗口后来明确选择的默认项。不能承诺浏览器崩溃或外部插件并发下绝对隔离。删除渠道不自动删除原生 Key，避免破坏其它引用；需删除 Key 时使用酒馆自己的管理器。

手机到酒馆若是 HTTP，页面给出可信网络/HTTPS 提示，不再把额外部署或启用服务器插件当作填写渠道的条件。

## 升级与旧服务

从 0.2.x 更新无需迁移或启动配套模块。新页面完全不访问 `/api/plugins/npc-independent-api`。已安装过旧服务的用户，其数据不会自动删除；旧副本更新后只保留停用提示，不处理密钥。未安装过的用户不用做任何电脑端操作。
